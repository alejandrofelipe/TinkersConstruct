## Design decisions (defaults; revisit if they fight the code)

- **D1 — BE serialization bridge:** keep Mantle's `saveSynced`-style hooks but move them to `ValueOutput`/`ValueInput` in one place (`MantleBlockEntity`), so the ~20 BEs change mechanically; where a BE stores an NBT blob (tool stacks, fluid/inventory helpers) use `CompoundTag.CODEC` / `ItemStack.OPTIONAL_CODEC` / `FluidStack.OPTIONAL_CODEC` via `store/read`. **Saved-world compatibility:** the on-disk NBT layout must stay the same keys/shapes (ValueIO writes NBT underneath) — add a gametest that round-trips a populated smeltery/table BE through save → load.
- **D2 — Entities:** same rule; ThrownTool/arrows store the tool stack with `ItemStack.OPTIONAL_CODEC` under the old key.
- **D3 — GUI tiled fluids:** replace the immediate-buffer `GuiUtil.renderTiledTextureAtlas` with `blitSprite(RenderPipelines.GUI_TEXTURED, sprite, …, color)` per tile (partial tiles via a scissor or a small custom `GuiElementRenderState` if sub-UV is needed) — one chokepoint for 13 callers.
- **D4 — Depth/z:** every `flush`/`clearDepth`/`fill(…, z)`/`MAX_GUI_Z` use becomes `graphics.nextStratum()` at the same place in the draw order.
- **D5 — Text colors:** opaque-alpha every literal (`0xFF404040`, …) and OR `0xFF000000` into colors read from data (book JSON, `getCoverTextColor`) at the read site, not per call.
- **D6 — PiP:** `StructureElement` gets a `PictureInPictureRenderer` + state (registered in `RegisterPictureInPictureRenderersEvent`); `BookCommand` (dev-only export) ports to `GuiGraphics(mc, GuiRenderState)` + `GuiRenderer` or is disabled with a clear message if PiP offscreen proves too costly (record the decision).
- **D7 — Fluid fog JSON:** drop `fog.shape` from the model (no equivalent), keep accepting it on read (ignored, logged once) so old data still loads; datagen stops writing it.
- **D8 — Shaders:** rewrite Mantle's `fluid` and `block_fullbright` shaders against the 1.21.8 UBO layout (extract vanilla `core/*.vsh`/`include/*.glsl` from the client jar as reference); verify visually in uitest (smeltery/melter/casting fluids, book fullbright, fluid fog both config variants).
