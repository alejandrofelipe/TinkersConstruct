# TinkersConstruct 1.21.1 / NeoForge Port — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Port TinkersConstruct from MC 1.20.1/Forge 47.4.0 to MC 1.21.1/NeoForge 21.1.234, consuming the
ported Mantle, to the point of a green build + in-game smoke test.

**Architecture:** Big-port-then-converge. The `library ↔ content` package graph is cyclic, so the mod is an
atomic deliverable that does not compile until all code leaves Forge. We migrate the build, mechanically
sweep the cataloged 1.20→1.21 transforms across the whole tree, port every package's semantic API changes in
parallel (edits-only subagents), then drive the full build's ~5,500–7,000 errors to zero, then datagen, then
runtime smoke test. Mantle's deferred stubs are finished in-flight via a Gradle composite build.

**Tech Stack:** Gradle 9.2.1 + NeoGradle 7.1.38 + foojay 1.0.0, JDK 21, NeoForge 21.1.234, Parchment
2024.11.17, JEI 19.21.0.247, Lombok 8.6. Design spec:
[`2026-06-27-tinkers-1.21.1-neoforge-port-design.md`](../specs/2026-06-27-tinkers-1.21.1-neoforge-port-design.md).

---

## How to execute this plan (read first)

This is a **mass port**, not greenfield feature work, so the task shape differs from typical TDD plans:

1. **Verification gate = compile/build, not unit tests.** A port task's "test" is "the package's Forge
   references are gone" (M1–M2) or "the full `build` error count dropped" (M3). The 50-file test suite is
   ported and run only at **M6** (per the design's locked decision).
2. **"Edits-only + controller compiles" pattern** (proven on the Mantle port): a porting subagent edits ONE
   package and reports its edits + any stubs — it does **not** run Gradle (Gradle hangs subagents). The
   **controller** runs the build (backgrounded, slow cold start) and feeds errors back to the same subagent
   via SendMessage. Commit per package once its gate is clean.
3. **Always verify with a clean `build`, never incremental `compileJava`** — incremental hides errors in
   untouched files. `-Xmaxerrs/-Xmaxwarns` are raised in M0 so javac's 100-error cap never masks the count.
4. **Canonical Gradle invocation** (PowerShell; daemon disabled, so background long runs):
   ```powershell
   $env:JAVA_HOME = "C:\Users\aleja\scoop\apps\temurin21-jdk\current"; & "C:\Users\aleja\DEV\New Tinkers\tinkers\gradlew.bat" -p "C:\Users\aleja\DEV\New Tinkers\tinkers" <task>
   ```
5. **Mantle is edited in-flight** on its `1.21.1` branch at `C:\Users\aleja\DEV\New Tinkers\repo`; the
   composite build picks the changes up with no republish. Commit Mantle changes there separately.
6. **Commit after every green milestone** (and every clean package in M2). Conventional-commits in English,
   ending with the `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>` trailer.

Per-subsystem migration detail referenced by the M2 tasks lives in the design spec §7–§8 and in the recon
digest; this plan inlines the concrete migration list per package.

### Task 6: Convert the access transformer SRG → mojmap

**Files:**
- Modify: `src/main/resources/META-INF/accesstransformer.cfg`

NeoForge 1.21 ATs use **mojmap** (readable) names, not SRG (`f_xxx_`/`m_xxx_`/`func_xxx_`). The current file
has ~150 SRG entries; **most carry the mojmap name in the trailing `# comment`** (e.g.
`f_20898_ # lastDamage` → `lastDamage`).

- [ ] **Step 1: Convert each entry to mojmap**
  - Field entry `public <CLASS> f_xxx_ # name` → `public <CLASS> name`.
  - Method entry `public <CLASS> m_xxx_(<DESC>)<RET> # name` → `public <CLASS> name(<DESC>)<RET>` (keep the
    descriptor; only the method *name* changes).
  - Keep field-reassignment entries as `public-f` (e.g. `Slot xPos`/`yPos`, `LootPool entries`).
  - For entries **without** a usable comment (e.g. the old `func_*` font/render entries on lines ~79–83,
    which reference 1.16-era names), look up the mojmap member in the MC 1.21.1 / Parchment source; if the
    member no longer exists in 1.21, **drop the entry** and record it in the commit body.
  - The Mantle AT (`../repo/src/main/resources/META-INF/accesstransformer.cfg`) is a worked mojmap example.

- [ ] **Step 2: Sanity-check the conversion is total**

